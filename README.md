# github-cli-gh-codex

这个仓库用于记录与复现「在本地机器上安装并使用 GitHub CLI（`gh`）」以及与仓库管理相关的操作脚本。

## 包含文件

- `install_gh_and_verify.sh`：安装并验证 `gh` CLI 的脚本。
- `cleanup_latest_only_lightsunion_outputs.sh`：保留最新文件的清理脚本。
- `cleanup_latest_only_lightsunion_outputs_direct_delete.sh`：按“直接删除其他重复项”规则清理文件的脚本。

## 当前仓库状态

- 这是一个可复用的最小示例仓库，主分支为 `main`。

## 使用方式

- 克隆后直接运行对应脚本即可。
- 仓库托管于 GitHub，便于后续在 Codex/PR/Issue 场景中进行管理与协作。
